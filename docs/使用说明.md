# 使用说明

> 只想知道「怎么用」，看这一篇就够；想改代码，看 [架构说明.md](架构说明.md)。

---

## 一、第一次运行

1. 准备内核：`xray.exe` 放到 `bin\`（见 README「准备内核」）。
2. `pip install -r requirements.txt`
3. `python ChromeDual.py`
4. 托盘图标出现 → 右键 → **打开主面板**。

首次运行会自动生成 `config/profiles.json`，里面是三条示例线路：

| id | 用途 |
|---|---|
| `profile-a` | 普通代理线路（建议改成你自己的第一份资料） |
| `profile-b` | 普通代理线路（第二份） |
| `direct` | 直连 + PAC 分流（国内直连、境外按名单分流） |

**没有内核也能先玩**：程序会生成一份占位直连配置，窗口能开、软件能点，
日志里会写「这是占位配置，不是真代理」。

---

## 二、日常怎么用

1. 右键托盘 → 打开主面板。
2. 点某条线路的**图标** → 该线路的内核起来（约 1 秒）→ Chrome 窗口打开。
3. 用完直接关窗口。**2 分钟内没有任何窗口，这条线的内核会自动停**（可配 `idle_stop_seconds`）。
4. 想一次全开：面板里有「启动全部」；但**平时不建议**——按需启动才是这个软件的意义。

面板里每条线路有五种状态：

| 状态 | 含义 |
|---|---|
| 运行中 | 内核在跑，Chrome 窗口开着 |
| 待机 | 正常空闲态，点它才会起内核 |
| 启动中 | 正在拉内核 |
| 遗留 | 上次退出时留下的孤儿内核，可以直接接管 |
| 被占用 | 端口被别的程序占了（不会去抢占，会自动换端口） |

## 三、加一条线路

`config/profiles.json` 的 `lines` 里追加一段：

```jsonc
{
  "id": "work",                 // 换一个新名字
  "name": "工作",
  "enabled": true,
  "http_port": 0,               // 0 = 随机
  "chrome": {
    "user_data_dir": "${ROOT}/data/chrome/work",
    "profile_directory": "Default",
    "startup_urls": ["https://mail.google.com/"]
  }
}
```

保存后重启管家。资料目录、订阅目录、备份目录都会按 `id` 自动分开。

> ⚠ **资料目录只能拆一次**。不要复制、不要改名、不要搬到别的盘 ——
> Chrome 127 之后的登录 Cookie 用应用绑定加密，密文里写死了目录绝对路径，
> 目录一变，Chrome 会**静默删掉**那批登录 Cookie（日志里一个字都没有）。
> 真要换目录，就当这条线要重新登录一次。

## 四、接入自己的代理

### 方式一：现成的 xray 配置

放到 `var\runtime\<线路 id>\xray-runtime.json`。

### 方式二：订阅地址

```bat
python tools\build_balancer_config.py ^
    --root data\source\work ^
    --sub-url "https://你的订阅地址/sub?token=xxx"
```

脚本会：拉订阅 → 并发探活 → 现场测速 → 挑最快的几个 → 生成 xray 配置。

**指定站点走指定国家**（对付有地域风控的站）：
在 `data\source\work\region-rules.json` 里写：

```json
[{"region": "US", "domains": ["example.com"], "probe": "https://www.example.com/"}]
```

## 五、系统默认浏览器

```bat
python tools\装成默认浏览器.py            # 注册 + 打开设置页
python tools\装成默认浏览器.py --check    # 看当前状态
python tools\装成默认浏览器.py --remove   # 撤销
```

注册完成后，去 **设置 → 应用 → 默认应用** 找到 `ChromeDual` 点「设为默认」
（Windows 不允许程序自己设默认，这一下必须你手动点）。

之后点微信/QQ/Word 里的链接，就会落到 `config/sysdefault.json` 指定的那条线路
**已登录的那个窗口**里 —— 不会另起一份资料。

想换线路：改 `config/sysdefault.json` 的 `line`，**不用重新注册**。

## 六、登录态守门员

### 掉了登录怎么办

1. 先看面板那一行下面的**橙色警示条**，它会告诉你「是在这次开窗之前就已经少了」。
2. 用找回工具（**先把该线路的 Chrome 全部关掉**）：

```bat
python tools\救回登录.py                 # 先看有什么，不动手
python tools\救回登录.py --apply --yes   # 真合并
```

它只把**登录类 Cookie** 从历史快照里合并回来，其余数据一律不动；
动手前必过 `safety.guard`（完整快照 + 审计日志）。

### 它防的是什么

| 机制 | 干什么 |
|---|---|
| 路径冻结 `var/state/frozen.json` | 资料目录路径登记后不许变，发现变了只报错、**绝不自动纠正** |
| 开窗前体检 | 开窗前只读地数 Cookie、比对密钥指纹，变少就报警 |
| 破坏性门禁 `app/safety.py` | 查占用 → 完整快照 → 明确确认 → 写审计日志 |

## 七、清理本地 AI 模型

Chrome 会往磁盘里塞本地 AI 模型（几个 GB）。要删干净并占位：

```bat
python tools\chrome_ai_cleanup.py --apply --yes --include-soda
```

删完会在原路径留一个**只读同名文件**，Chrome 建不了同名目录，也删不掉。

## 八、端口

端口**全部随机分配**，写进 `var/run/ports.json`，重启沿用。

每次启动复核：不在随机区间、落在 10800–10999、被别的程序占了、两条线撞了同一个
→ 全部自动重挑。自家内核正在跑的端口不会被动。

想全部重新洗一遍：删掉 `var/run/ports.json` 再启动。

## 九、出问题先看哪里

| 现象 | 先看 |
|---|---|
| 面板打不开 | `var/logs/guard.log` |
| 某条线起不来 | `var/logs/<线路 id>.log` |
| 内核自己报错了 | `var/logs/<线路 id>-core.log` |
| 破坏性操作被拦 | `var/logs/destructive.log` |
| 登录态异常 | `var/logs/login-events.log` |
| 系统默认浏览器没反应 | `var/logs/sysdefault.log` |

## 十、几个常见误解

**「管家一启动就该把代理都起好」**
不是。默认是按需启动，窗口开了才起对应内核。这是刻意的设计，见 README「按需启动」。

**「为什么这台机器上端口不是 10888 了」**
端口随机化是防冲突的，别再改回固定值。

**「改程序会不会把我的登录改没了」**
程序代码在 `app\`，资料在 `data\chrome\`，两者完全分开。
真正危险的是**搬动/复制资料目录**和**Chrome 大版本升级**，
这两件事都有守门员盯着并会明确提示。

**「能不能改成 Edge / Brave」**
浏览器参数走的是标准 Chromium 参数，改 `config/profiles.json` 里的 `chrome` 路径即可。
